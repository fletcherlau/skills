# 阶段路由与产物

页数为层级提示，表内输入均可由已有材料提供。编号只表达原方法对应关系。

| 步骤 / 技能 | 当前需求 | 常用输入 | 建议产物 |
| --- | --- | --- | --- |
| [1 · snowflake-01-premise](../skills/snowflake-01-premise/SKILL.md) | 一句话故事 | 灵感、已有故事片段或已有稿件的事实摘要；作者已有题材、文风及禁区。 | `01-premise.md` |
| [2 · snowflake-02-paragraph](../skills/snowflake-02-paragraph/SKILL.md) | 一段式梗概 | 一句话核心或等价故事材料；已知结局/结局候选。 | `02-paragraph.md` |
| [3 · snowflake-03-character-summary](../skills/snowflake-03-character-summary/SKILL.md) | 人物摘要 | 故事核心、短梗概或等价材料；主要人物清单。 | `03-characters.md` |
| [4 · snowflake-04-short-synopsis](../skills/snowflake-04-short-synopsis/SKILL.md) | 短篇幅故事梗概 | 一段式梗概、人物摘要或等价大纲。 | `04-short-synopsis.md` |
| [5 · snowflake-05-character-synopsis](../skills/snowflake-05-character-synopsis/SKILL.md) | 人物视角故事梗概 | 故事短梗概、人物摘要或等价故事材料；本次选定的视角人物。 | `05-character-synopses.md` |
| [6 · snowflake-06-long-synopsis](../skills/snowflake-06-long-synopsis/SKILL.md) | 长篇幅故事梗概 | 短故事梗概、人物视角梗概或已有详细大纲。 | `06-long-synopsis.md` |
| [7 · snowflake-07-character-bible](../skills/snowflake-07-character-bible/SKILL.md) | 详细人物档案 | 人物摘要、视角梗概、故事梗概或稿件中的人物事实。 | `07-character-bible.md` |
| [8 · snowflake-08-scene-list](../skills/snowflake-08-scene-list/SKILL.md) | 场景清单 | 详细梗概与人物档案，或可拆分的已有稿件/章节大纲。 | `08-scenes.md` |
| [9 · snowflake-09-scene-plan](../skills/snowflake-09-scene-plan/SKILL.md) | 场景扩写计划（可选） | 选定场景 ID 的场景行、相关人物事实与前后场景；或等价场景构想。 | `09-scene-plans.md` |
| [10 · snowflake-10-draft-scene](../skills/snowflake-10-draft-scene/SKILL.md) | 按场景创作初稿 | 指定场景/续写位置、已有正文尾段、相关场景表与人物事实；第 9 步计划若存在则参考。 | `draft/S001.md` |

各步完成条件在独立 SKILL.md 中；第 3/5/7 步和第 9/10 步都可按人物或场景局部完成。导航不以最大编号表示整体进度。
