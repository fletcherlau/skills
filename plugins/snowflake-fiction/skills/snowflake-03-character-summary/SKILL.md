# 雪花第 3 步：人物摘要

默认中文交互，遵循作者选择。本步可独立使用、从等价材料接入或返回修订；编号不是强制执行顺序。

## 开始前

读取 [共同工作协议](../../references/workflow.md)，执行其中的范围确认、状态恢复和写入规则。方法出处见 [来源说明](../../references/sources.md)，需要核对方法归属时读取。

输入：故事核心、短梗概或等价材料；主要人物清单。

输入不足时只补当前任务必要信息，区分原材料事实、作者决定与候选；不能自动替作者确定故事。

## 本步工作

为本次范围内的主要人物建立稳定人物 ID，区分抽象动机与可观察的目标。写人物线的一句话和一段摘要，梳理冲突与可能的领悟；允许不发生正向成长。不要为补满表格发明年龄、家庭或价值观。人物驱动力若改变故事，提出回退第 1/2 步的具体影响。

使用 [本步模板](assets/template.md) 组织产物，可适配作者原格式。建议产物为 `<项目目录>/03-characters.md`；确认目录后才写入，不在插件目录中保存小说。

## 完成与一致性

完成条件：选定主要人物均有动机、目标、阻力、变化方向和人物线摘要；未知项可显式待定，且不会阻断当前用途。

检查重点：人物选择能解释第 2 步转折；目标变化与结局兼容。

按共同协议记录本步状态、产物版本、依据、作者决定、未决项及下一入口；局部完成不要冒充全步完成。上游发生变化时对受影响项标记 stale，保留旧稿并提供回退修订路径。
