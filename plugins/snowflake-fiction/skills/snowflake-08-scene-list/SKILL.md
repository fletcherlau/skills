# 雪花第 8 步：场景清单

默认中文交互，遵循作者选择。本步可独立使用、从等价材料接入或返回修订；编号不是强制执行顺序。

## 开始前

读取 [共同工作协议](../../references/workflow.md)，执行其中的范围确认、状态恢复和写入规则。方法出处见 [来源说明](../../references/sources.md)，需要核对方法归属时读取。

输入：详细梗概与人物档案，或可拆分的已有稿件/章节大纲。

输入不足时只补当前任务必要信息，区分原材料事实、作者决定与候选；不能自动替作者确定故事。

## 本步工作

按叙述顺序拆分场景；章节与场景分开，一章可有多个场景。使用稳定场景 ID（重排不改 ID），记录 POV、时地、发生什么及前后变化。篇幅估计和章节号可选，不硬定场景数。检查转折与支线是否被场景覆盖。稿件接入时保留原章节/段落定位，区分已经写过与计划新增。可使用 Markdown 表或作者已有表格，不要求特定软件。

使用 [本步模板](assets/template.md) 组织产物，可适配作者原格式。建议产物为 `<项目目录>/08-scenes.md`；确认目录后才写入，不在插件目录中保存小说。

## 完成与一致性

完成条件：本次故事范围的场景表有唯一 ID、POV、事件和变化；顺序与衔接可检查，缺场景已列明。

检查重点：对照第 6 步事件覆盖及第 7 步视角知识；重排时核对时间、伏笔、信息揭示。

按共同协议记录本步状态、产物版本、依据、作者决定、未决项及下一入口；局部完成不要冒充全步完成。上游发生变化时对受影响项标记 stale，保留旧稿并提供回退修订路径。
