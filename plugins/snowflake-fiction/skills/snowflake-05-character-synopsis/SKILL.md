# 雪花第 5 步：人物视角故事梗概

默认中文交互，遵循作者选择。本步可独立使用、从等价材料接入或返回修订；编号不是强制执行顺序。

## 开始前

读取 [共同工作协议](../../references/workflow.md)，执行其中的范围确认、状态恢复和写入规则。方法出处见 [来源说明](../../references/sources.md)，需要核对方法归属时读取。

输入：故事短梗概、人物摘要或等价故事材料；本次选定的视角人物。

输入不足时只补当前任务必要信息，区分原材料事实、作者决定与候选；不能自动替作者确定故事。

## 本步工作

以人物自己的理解重述开端至结局：其想要什么、如何解读局势、作何选择、付出何种代价。反派请求同样使用此步。主要人物可写约一页量级，其他重要人物可更短；不限定页数。区分故事真实事件与人物误解，不赋予其不知道的信息。背景只写影响当下选择的部分。

使用 [本步模板](assets/template.md) 组织产物，可适配作者原格式。建议产物为 `<项目目录>/05-character-synopses.md`；确认目录后才写入，不在插件目录中保存小说。

## 完成与一致性

完成条件：本次选定人物的完整故事线可读；行动及变化可解释，共享事件与整体梗概能互相对照。

检查重点：检查视角知识边界；若发现事件冲突，列出双方证据并回退第 2/4 步或人物第 3 步，不能暗改共享事实。

按共同协议记录本步状态、产物版本、依据、作者决定、未决项及下一入口；局部完成不要冒充全步完成。上游发生变化时对受影响项标记 stale，保留旧稿并提供回退修订路径。
