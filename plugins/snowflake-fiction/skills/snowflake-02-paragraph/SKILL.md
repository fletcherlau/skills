# 雪花第 2 步：一段式梗概

默认中文交互，遵循作者选择。本步可独立使用、从等价材料接入或返回修订；编号不是强制执行顺序。

## 开始前

读取 [共同工作协议](../../references/workflow.md)，执行其中的范围确认、状态恢复和写入规则。方法出处见 [来源说明](../../references/sources.md)，需要核对方法归属时读取。

输入：一句话核心或等价故事材料；已知结局/结局候选。

输入不足时只补当前任务必要信息，区分原材料事实、作者决定与候选；不能自动替作者确定故事。

## 本步工作

将核心展开成一段因果链，写出开端、几次改变局势的转折和结局。原方法约五句、三次灾难可用作骨架；作者选择其他结构时记录对应转折，不硬套三幕或均分篇幅。检查每次选择为何导致下一局势。未知结局先提出选项或询问，不能悄悄定案。

使用 [本步模板](assets/template.md) 组织产物，可适配作者原格式。建议产物为 `<项目目录>/02-paragraph.md`；确认目录后才写入，不在插件目录中保存小说。

## 完成与一致性

完成条件：一段覆盖故事开端到结局的梗概；转折有因果，结局可暂定但必须明确标注。

检查重点：对照第 1 步的故事承诺与主角；新增结构选择进入决策记录。

按共同协议记录本步状态、产物版本、依据、作者决定、未决项及下一入口；局部完成不要冒充全步完成。上游发生变化时对受影响项标记 stale，保留旧稿并提供回退修订路径。
