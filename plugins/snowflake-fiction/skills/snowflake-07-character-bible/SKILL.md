# 雪花第 7 步：详细人物档案

默认中文交互，遵循作者选择。本步可独立使用、从等价材料接入或返回修订；编号不是强制执行顺序。

## 开始前

读取 [共同工作协议](../../references/workflow.md)，执行其中的范围确认、状态恢复和写入规则。方法出处见 [来源说明](../../references/sources.md)，需要核对方法归属时读取。

输入：人物摘要、视角梗概、故事梗概或稿件中的人物事实。

输入不足时只补当前任务必要信息，区分原材料事实、作者决定与候选；不能自动替作者确定故事。

## 本步工作

按人物 ID 扩展已有材料，只补与故事选择、关系、声音或连续性有关的背景与细节。年龄、外貌、经历等可保持未知；区分已确认、候选、人物自述和推测。写出起点到结局的变化及关键依据。世界规则可附于事实表，避免凭空增设设定。

使用 [本步模板](assets/template.md) 组织产物，可适配作者原格式。建议产物为 `<项目目录>/07-character-bible.md`；确认目录后才写入，不在插件目录中保存小说。

## 完成与一致性

完成条件：本次人物档案能支持其行动、关系及声音的一致性；事实有出处和确认状态，关键变化可追踪。

检查重点：对照第 3/5 步人物线和第 6 步关键行为；关系、时间、能力及知识没有未处理冲突。

按共同协议记录本步状态、产物版本、依据、作者决定、未决项及下一入口；局部完成不要冒充全步完成。上游发生变化时对受影响项标记 stale，保留旧稿并提供回退修订路径。
